# SQL Exercise 4 – UNION & UNION ALL

## About

This repository contains my submission for Exercise 4: "UNION & UNION ALL." The exercise covers 10 handwritten SQL queries combining the results of two `SELECT` statements, plus 3 bonus questions on when to use each operator and why a `UNION` can fail. The queries are based on banking data such as accounts, products, staff, transactions, loan applications, complaints, payments, and ledger entries.

## Contents

- `SQL-Exercise-4.pdf` – scanned handwritten SQL queries with expected output tables and written bonus answers

## Topics Covered

- Combining result sets with `UNION`
- Keeping duplicate rows with `UNION ALL`
- Removing duplicates across two queries
- Filtering with `NOT IN` to avoid overlapping rows
- Sorting combined results with `ORDER BY`
- Matching the number, order, and data types of columns in a `UNION`
- Choosing between `UNION` and `UNION ALL` for a given scenario
